# Recursion & Backtracking

A collection of **Recursion and Backtracking** problems and solutions implemented in **C++**.

This repository is focused on building a strong understanding of recursive problem-solving, breaking problems into smaller subproblems, and exploring multiple possibilities using backtracking.

## 📚 Topics Covered

### 🔁 Recursion

* Basic recursion
* Recursive tree and call-stack understanding
* Mathematical recursion
* Array and string problems
* Subsequences and subsets
* Recursive sorting
* Divide and conquer concepts
* Recursion-based problem solving

### 🔙 Backtracking

* Subsets and subsequences
* Permutations
* Combination problems
* String partitioning
* Maze and path problems
* N-Queens
* Sudoku
* Constraint-based problems
* Generating all possible solutions


## 🧠 Problem-Solving Approach

For most problems, the solutions focus on:

1. Identifying the **base case**.
2. Defining the **recursive relation**.
3. Making the required choice.
4. Recursively solving the remaining problem.
5. **Backtracking** when exploring multiple choices.
6. Analyzing time and space complexity.

## 💻 Language

* **C++**

## 🎯 Goal

The main goal of this repository is to practice recursion and backtracking extensively and develop the ability to recognize when these techniques can be applied to DSA problems.
